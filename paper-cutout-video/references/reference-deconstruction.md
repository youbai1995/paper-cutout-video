# 参考视频拆解与跨风格迁移指南

本 Skill 支持“视觉语言迁移”：**原片可以不是纸雕或剪纸风格**（例如实拍物理实验、传统扁平动画、纪录片航拍、白板推演或产品发布会录屏），只要内容属于**历史路线、地理气象、物理机制、科学剖面、人物关系或产品实测**，都可以拆解其叙事与镜头机制，再重构为本 Skill 的 **2D/2.5D 剪纸拼贴** 或 **3D 纸雕立体舞台（`@remotion/three`）**。

> 硬原则：只迁移原片的**结构、节奏、镜头调度和信息揭示顺序**，不得复制受版权保护的原片画面、素材或未核实的结论。

---

## 1. 推荐可拆解的视频方向与代表原型

| 领域方向 | 可对标的外部视频原型（非纸艺风格） | 原片核心叙事机制 | 推荐本 Skill 映射方案 |
|---|---|---|---|
| **历史与地图路线** | **Vox**《Borders》系列 / 历史地图频道（如 Kings and Generals 路线推演） | 宏观地图定标 → 区域染色扩张 → 箭头/补给线推进 → 关键战役/人物卡片弹出 | `hybrid` + `scroll-unfold`（3D 横向画卷逐段摊平 + 立体船队/城楼立起 + 2D 精准史料图框） |
| **地理与气象机制** | **央视《地理·中国》/ BBC Earth** 气候与洋流解说片段 | 地球/区域俯瞰 → 太阳光照/海温变化 → 风带/洋流箭头流动 → 局部地貌成因 | `3d-diorama` + `globe-orbit`（23.5° 倾角 3D 地球 + 昼夜晨昏线 Shader + 3D 流动风带箭头） |
| **物理实验与力学** | **中学/大学物理实验实拍、3Blue1Brown / Veritasium** 力学与能量可视化 | 实验装置搭建 → 释放触发过程 → 受力矢量分解 → 能量/动量定量对比 | `3d-diorama`（3D 可折叠实验台 + 刻度尺 + 弹簧回弹物理曲线 + 实时 `Ep/Ek/Ee` 能量柱看板） |
| **生物/地质结构科普** | **Kurzgesagt / 博物科普** 剖面拆解动画 | 外观建立 → 切开剖面 → 由内而外逐层点亮机理 → 外部环境连锁反应 | `hybrid` + `book-spread`（对开立体书 + 3/4 地质/器官多层切面 + 熔岩/血液动态通道 + 高清标牌） |
| **商业流程与产品实测** | **产品发布会 Benchmark 对比 / 商业案例拆解** | 痛点提出 → 对比基准建立 → 真实界面/测试结果呈现 → 关键指标放大批注 | `2d-cutout` 或 `2.5d-fold` + `evidence-fold`（牛皮纸封门折开 → 0° 零畸变真实截图 → 纸质批注立起） |

## 2. 跨风格拆解四步法（拿到任意参考视频时执行）

### 第一步：剥离原片画风，提取“信息节拍表”
观看原片时，忽略它的配色和画风，只按 **1.5–2.5 秒一拍** 记录：
1. 当前这一拍在回答什么问题？（语境 / 冲突 / 机理 / 证据 / 结论）
2. 画面里同时有几个视觉焦点？（超过 1 个时，在重构中拆成错峰入场）
3. 信息变化的方向是什么？（从左到右的时间推进、从外到内的剖面切入、还是 A/B 对照）

### 第二步：匹配渲染轨道与展开形态
- 若信息核心是**精准截图、网页 UI、数据表格**：选 `2d-cutout` 或 `2.5d-fold`（`evidence-fold`），保证证据图层 0° 正交清晰。
- 若信息核心是**空间关系、光照昼夜、力学运动、地层剖面、长距离迁徙**：选 `3d-diorama` 或 `hybrid`，用 Three.js 建出分层立体模型与软阴影。

### 第三步：将原片动作“翻译”为纸艺物理语言

| 原片常见手法 | 翻译为 2D/2.5D 剪纸语言 | 翻译为 3D 纸雕语言 |
|---|---|---|
| 镜头快速横摇切换地点 | 纸张背景平移 + `clipPath` 方向揭示 | `scroll-unfold` 横向画卷逐段摊平，每摊平一段立起对应地标 |
| 黑板/PPT 擦除重画 | `accordion-fold` 手风琴折页翻折切换 | `book-spread` 书页合拢再展开，或支撑底座立起新舞台 |
| 实拍实验慢动作回放 | 局部证据框放大 + `LineDraw` 标注箭头 | 3D 装置按确定性物理曲线运行（压缩→回弹）+ 实时能量柱 |
| 3D CG 剖面透视 | 多层带白边剪纸错峰叠加 | 270° 外坡 + 90° 阶梯地质/结构切面 + 悬浮引线纸标牌 |

### 第四步：补齐真实性来源与“停驻后生命力”
1. 原片中引用的数据、地图边界、实验公式，必须重新核验并在 `assets-manifest.md` 标注 `OFFICIAL` / `REAL LOCAL` / `EXPLAINER`。
2. 为每个镜头预留 **0.8–1.5 秒定格阅读时间**，定格期间保持环境微动（风带流动、云朵飘移、航线光点循环），避免画面死板凝固。
