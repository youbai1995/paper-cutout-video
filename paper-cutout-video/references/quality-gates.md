# 成片质量门槛

## 目录

1. 阻断项
2. 视觉检查
3. 时间与声音
4. 技术检查
5. 交付记录

## 1. 阻断项

以下任一项失败时不得称为成片：

- 事实、时间、数据、地图、路线、关系、界面或标签存在错误；
- 仍有未标记 `PLACEHOLDER`；
- 主体、证据、地图、截图或音乐来源/许可不清；
- 出现黑帧、绿帧、闪帧、明显路径跳变或透明通道绿边；
- 字幕遮挡关键证据、标签、线条或主体；
- 旁白、字幕和画面含义不一致；
- 工程无法重新渲染。

## 2. 视觉检查

逐项检查：

- 开头 0–3 秒能看懂问题或结果；
- 真实证据先于解释标签进入，来源清楚；
- 纸片或区域按叙事方向揭示；
- 关系线、路线或时间线绘制连续，方向正确；
- 虚线、箭头或节点运动速度和循环接缝正确；
- 背景、纸片、线条和剪纸材质统一；
- 剪纸白边、阴影方向与纸张材质是否统一；
- 主体错峰出现，没有同时塞满；
- **2.5D/3D 纸雕专项检查**：
  - 展开关键帧（0% / 25% / 50% / 75% / 100%）中，底板未摊平前上方主体不得提前浮空出现；
  - **翻页与折叠坐标对齐**：禁止在翻页背面直接叠加 `rotation.z = Math.PI` 导致子物体坐标轴反转错位；多页叠放须显式计算纸张堆叠高度（Stacking Offset），确保翻页前后不穿模、不遮挡底图路径；
  - **场景密度与生动性**：每个跨页/舞台须包含**地面微细节（路径/石阶/草丛/码头）+ 前中后多层景深 + 主体精细拆解（门窗框/台基/栏杆）+ 角色微动态**，禁止“单建筑 + 光秃圆锥树”的草稿感；
  - 实时阴影方向一致，无背面穿模或悬空脱节；
  - 同一帧号重复渲染必须像素级一致（确定性帧驱动）。
- 标签与对应对象空间关系明确；
- 字幕处于安全区且可读；
- 没有复刻录屏黑边、状态栏或播放器 UI。

## 3. 时间与声音

- 旁白决定镜头时长，不强压语速匹配预设长度；
- 字幕逐句对齐旁白，切换点没有半句残留；
- 每个音效与动作峰值相差不超过数帧；
- 背景音乐不遮盖人声；
- 独立音频首尾约 30ms 淡化；
- 社交平台口播可从约 -16 LUFS 开始校准，并记录最终响度和真峰值。

## 4. 技术检查

至少完成：

```bash
ffprobe -v error -show_streams -show_format -of json final.mp4
```

并执行：

- 开头、结尾代表帧；
- 每个关键动作开始、完成和中点帧；
- 每次转场前后约 ±1.5 秒；
- 全片快速播放和逐帧抽查；
- 异常绿色帧检测；
- 综合响度、动态范围和真峰值检查；
- 最终文件 SHA-256 校验。

输出参数默认：1920×1080、30fps、H.264/AAC；如用户指定 60fps 或其他编码，以 brief 为准。

## 5. 交付记录

在 `edit/project.md` 追加：

- 成片和工程绝对路径；
- 渲染日期与命令；
- 视频参数与时长；
- 响度和真峰值；
- 代表帧与转场检查路径；
- SHA-256；
- 素材真实性和许可状态；
- 未解决限制与可选升级。
