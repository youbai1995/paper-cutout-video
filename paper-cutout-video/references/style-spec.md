## 1. 画面系统

默认输出为 1920×1080、16:9、30fps。需要更丝滑的路径和弹性动作时使用 60fps。不要复刻录屏产生的黑边或播放器 UI。

### 色彩

保持 3–5 个主要颜色：

- 纸张底色：米白、浅褐或低饱和灰；
- 强调色 A/B：按主题选择一冷一暖或一主一次；
- 线条/路径：比对应纸片更深的同色；
- 字幕与剪纸描边：白色；
- 标签：深褐或接近黑色。

所有彩色覆盖层叠加纸纹或 2%–6% 噪点，并用适度透明度或 multiply/overlay 混合融入底板。

### 构图

- 主要环境、证据或场景占满画布，不缩成无法阅读的小卡片。
- 字幕安全区距底边约画面高度 5%–9%，避免盖住关键主体。
- 主体剪纸不要平均排布；按叙事重要性拉开尺寸。
- 同时出现的标签不超过 2 个；每个标签紧邻其解释对象。
- 早期推镜应指向后续信息聚集区。

## 2. 图层系统

从后到前：

```text
纸张纹理/环境底板
真实证据或事实结构
纸片区域/卡片/遮罩
关系线/路线/时间线
方向标记与解释图标
标签与来源标识
主体剪纸
品牌标识
字幕
```

动态覆盖层不得烘焙进背景。需要动画的每个图层必须单独命名并在 `assets-manifest.md` 记录来源。

## 3. 场景语法

### map-route

地图建立 → 区域揭示 → 路径绘制 → 流向运动 → 主体出现 → 结论。准确地理结构使用可信地图或矢量数据。

### timeline-process

语境纸条 → 时间节点/步骤卡片 → 连线推进 → 阶段性主体 → 最终结果。时间顺序必须与口播一致。

### relationship-board

核心人物/概念 → 次级节点 → 关系线 → 标签解释 → 关系全貌。一次只新增一条主要关系，避免一开始塞满关系网。

### comparison

先建立统一背景，再依次展示 A、B 的同一维度；最终合并到一张结论卡。只有在可读性足够时才使用分屏。

### product-story

真实界面或结果先进入，再用纸张标签、箭头和剪纸主体解释。不得重绘虚假产品 UI 冒充实测。

## 4. 动画语法

### 镜头

- 0–5 秒可从 1.00 缓慢推到 1.04–1.08；不要持续大幅摇镜。
- 背景最慢，解释层中速，主体弹入最快。
- 每个动作都服务于口播含义，不做无信息价值的随机漂浮。

### 纸片与区域

- 沿叙事方向揭示，时长通常 0.8–2.5 秒。
- 边缘可用多层不同宽度/透明度或透明遮罩制造手工质感。
- 不使用整张信息层的简单 opacity 淡入替代有方向的揭示。

### 线条、路径与流向

- 主线先绘制完成，再启动虚线、箭头或节点脉冲。
- 路线绘制使用 ease-out；持续流动保持线性。
- 循环点放在画面外或不显眼位置，避免明显跳帧。

### 剪纸主体

- 使用透明 PNG/WebP，完整主体，白边宽度视觉一致。
- 入场顺序遵循主角 → 次要主体 → 陪衬；间隔通常 0.25–0.7 秒。
- 入场使用缩放、轻位移和少量旋转，时长通常 0.35–0.65 秒。
- 入场后只保留 1%–2.5% 幅度的漂浮或 ±1° 旋转。

## 5. 字幕与声音

- 每次字幕保持一行优先，最多两行；每页约 0.8–1.8 秒。
- 字幕使用粗体白字、2–4px 深色描边/阴影。
- 纸片揭示配柔和 whoosh，连线完成配轻 impact，主体弹入配 pop/tick。
- 背景音乐不抢人声；所有动作音效与对应帧对齐。

15 秒单场景参考节奏：

| 时间 | 信息动作 |
|---|---|
| 0.0–1.6s | 建立问题与环境 |
| 1.6–3.8s | 第一解释层出现 |
| 3.8–6.0s | 第二解释层或标签出现 |
| 6.0–8.5s | 关系线/路线/时间线形成 |
| 8.5–10.5s | 方向或过程运动开始 |
| 10.5–13.0s | 结果主体错峰出现 |
| 13.0–15.0s | 稳定构图并给结论 |

## 6. 禁止项

- 必须准确的结构完全依赖生成式图片；
- 所有层同时出现；
- 全图元素同速、同方向移动；
- 大量高饱和颜色；
- 纯色矢量覆盖层与纸张底板材质割裂；
- 字幕挡住证据、路径、图标或关键主体；
- 把录屏黑边、播放器提示或状态栏当作设计元素；
- 用无法验证的数字、界面、关系或路线冒充真实证据。
