## 1. 画面系统

默认输出为 1920×1080、16:9、30fps。需要更丝滑的路径和弹性动作时使用 60fps。不要复刻录屏产生的黑边或播放器 UI。

### 色彩

保持 3–5 个主要颜色：

- 纸张底色：米白、浅褐或低饱和灰；
- 强调色 A/B：按主题选择一冷一暖或一主一次；
- 线条/路径：比对应纸片更深的同色；
- 字幕与剪纸描边：白色；
- 标签：深褐或接近黑色。

所有彩色覆盖层叠加纸纹或 2%–6% 噪点，并用适度透明度或 multiply/overlay 混合融入底板。

### 构图

- 主要环境、证据或场景占满画布，不缩成无法阅读的小卡片。
- 字幕安全区距底边约画面高度 5%–9%，避免盖住关键主体。
- 主体剪纸不要平均排布；按叙事重要性拉开尺寸。
- 同时出现的标签不超过 2 个；每个标签紧邻其解释对象。
- 早期推镜应指向后续信息聚集区。

## 2. 图层系统

从后到前：

```text
纸张纹理/环境底板
真实证据或事实结构
纸片区域/卡片/遮罩
关系线/路线/时间线
方向标记与解释图标
标签与来源标识
主体剪纸
品牌标识
字幕
```

动态覆盖层不得烘焙进背景。需要动画的每个图层必须单独命名并在 `assets-manifest.md` 记录来源。

## 3. 场景语法与纸艺渲染轨道

### 双轨渲染选型

保留 **2D/2.5D 剪纸拼贴** 与 **3D 纸雕立体舞台（`@remotion/three`）** 双轨并存：

| 渲染轨道 | 适用场景 | 核心表现手段 | 真实性保障 |
|---|---|---|---|
| `2d-cutout` | 纯图文快节奏解说、产品录屏/截图拆解 | `clipPath` / SVG `<mask>`、`evolvePath`、`spring` 弹入 | 截图与图表 0° 正交无变形 |
| `2.5d-fold` | 步骤对比、封门揭晓 | CSS 3D `rotateX/Y` + 折痕暗度遮罩 + 动态接触阴影 | 摊平后保持 0° 平面 |
| `3d-diorama` | 地理地球仪、物理力学实验、多层地质/建筑剖面、长卷立体路线 | Three.js `flatShading: true` + 程序化纸纤维 `CanvasTexture` + `2048px PCFSoftShadowMap` | 物理公式/坐标/比例严格受控 |
| `hybrid`（推荐） | 绝大多数深度科普视频 | 3D 纸雕舞台做主叙事 + 2D Remotion 叠加精准证据框、数据图与字幕 | 兼顾空间表现力与像素级证据清晰 |

### 五种纸艺展开形态（`foldStyle`）

- `scroll-unfold`（横向画卷）：沿垂直折痕从左向右分段摊平，每摊平一段（>92%）才立起对应地标与航线。
- `accordion-fold`（手风琴折页）：Z 字形多折页依次弹开，保留相邻折面明暗受光差，连线跨越折痕推进。
- `book-spread`（中轴对开立体书）：绕竖直书脊对称摊平，摊平瞬间主体从底部铰链立起或呈现 3/4 剖面。
- `evidence-fold`（证据折封揭晓）：外层牛皮纸封门向两侧折开，露出内部 0° 无损真实界面/图表，再立起批注签。
- `globe-orbit`（倾斜地球仪舞台）：23.5° 黄赤交角支架 + 昼夜晨昏线 Shader + 夜光城市 + 3D 气流/洋流丝带。

### 3D 纸雕表现模式与细节约束

在 `3d-diorama` / `hybrid` 轨道中，根据主体特征选用或混用两种表现模式：

- **`pop-up-cutout`（立体贺卡插片）**：适合城市地标、历史建筑、人物群像。使用具备真实光影的照片级透明 PNG 沿轮廓裁切，以**前、中、后多层纸片**错落立起营造纵深，底部附带纸质**折脚（Hinge Tab）**与可见的薄纸侧边。
- **`lowpoly-papercraft`（3D 折纸几何体）**：适合地球仪、物理实验装置、地质/机械剖面。使用 `flatShading: true` 拆解底座、立柱、分层切面与量化标牌。

通用细节与空间规则：
1. **同图空间连续性与微缩运镜**：路线、城市或宏观演进题材优先共用同一张世界坐标底板，已立起的地标不随镜头移动而消失；运镜可结合贴近纸面的微距跟拍、低角度看折脚与薄纸侧边、环绕及结尾拉升俯瞰全景。
2. **程序化纸纹与真实厚度**：所有纸面均须叠加纤维噪点/短纤维丝（`CanvasTexture`）与折痕压暗渐变；纸张几何体须带物理厚度侧面，避免单面纸片穿帮。
3. **物理与光影自洽（AI 主动推演）**：根据主题主动补全内在的物理因果、环境动态与光影氛围过渡（如力学系统的完整碰撞回弹与能量守恒展示、地理/气象的光影与气流变化、或从开场到收尾的氛围递进），并用 `2048px PCFSoftShadowMap` 保持阴影统一。

### 3.2 五大内容语法

### map-route

地图建立 → 区域揭示 → 路径绘制 → 流向运动 → 主体出现 → 结论。准确地理结构使用可信地图或矢量数据。

### timeline-process

语境纸条 → 时间节点/步骤卡片 → 连线推进 → 阶段性主体 → 最终结果。时间顺序必须与口播一致。

### relationship-board

核心人物/概念 → 次级节点 → 关系线 → 标签解释 → 关系全貌。一次只新增一条主要关系，避免一开始塞满关系网。

### comparison

先建立统一背景，再依次展示 A、B 的同一维度；最终合并到一张结论卡。只有在可读性足够时才使用分屏。

### product-story

真实界面或结果先进入，再用纸张标签、箭头和剪纸主体解释。不得重绘虚假产品 UI 冒充实测。

## 4. 动画语法

### 镜头

- 0–5 秒可从 1.00 缓慢推到 1.04–1.08；不要持续大幅摇镜。
- 背景最慢，解释层中速，主体弹入最快。
- 每个动作都服务于口播含义，不做无信息价值的随机漂浮。

### 纸片与区域

- 沿叙事方向揭示，时长通常 0.8–2.5 秒。
- 边缘可用多层不同宽度/透明度或透明遮罩制造手工质感。
- 不使用整张信息层的简单 opacity 淡入替代有方向的揭示。

### 线条、路径与流向

- 主线先绘制完成，再启动虚线、箭头或节点脉冲。
- 路线绘制使用 ease-out；持续流动保持线性。
- 循环点放在画面外或不显眼位置，避免明显跳帧。

### 剪纸主体

- 使用透明 PNG/WebP，完整主体，白边宽度视觉一致。
- 入场顺序遵循主角 → 次要主体 → 陪衬；间隔通常 0.25–0.7 秒。
- 入场使用缩放、轻位移和少量旋转，时长通常 0.35–0.65 秒。
- 入场后只保留 1%–2.5% 幅度的漂浮或 ±1° 旋转。

## 5. 字幕与声音

- 每次字幕保持一行优先，最多两行；每页约 0.8–1.8 秒。
- 字幕使用粗体白字、2–4px 深色描边/阴影。
- 纸片揭示配柔和 whoosh，连线完成配轻 impact，主体弹入配 pop/tick。
- 背景音乐不抢人声；所有动作音效与对应帧对齐。

15 秒单场景参考节奏：

| 时间 | 信息动作 |
|---|---|
| 0.0–1.6s | 建立问题与环境 |
| 1.6–3.8s | 第一解释层出现 |
| 3.8–6.0s | 第二解释层或标签出现 |
| 6.0–8.5s | 关系线/路线/时间线形成 |
| 8.5–10.5s | 方向或过程运动开始 |
| 10.5–13.0s | 结果主体错峰出现 |
| 13.0–15.0s | 稳定构图并给结论 |

## 6. 禁止项

- 必须准确的结构完全依赖生成式图片；
- 所有层同时出现；
- 全图元素同速、同方向移动；
- 大量高饱和颜色；
- 纯色矢量覆盖层与纸张底板材质割裂；
- 字幕挡住证据、路径、图标或关键主体；
- 把录屏黑边、播放器提示或状态栏当作设计元素；
- 用无法验证的数字、界面、关系或路线冒充真实证据。
