## 1. 项目定义

本模板用于制作历史科普、自然现象、人物关系、事件演变、商业流程、产品故事、地图路线和数据解说。固定视觉语言为：

```text
纸张/浮雕环境底板
+ 可验证的事实结构或真实证据
+ 纸片、关系线、路径和标签组成的解释动画
+ 带白边的照片或插画剪纸主体
+ 与旁白同步的单层字幕
```

它不是一键文生视频流程。生成模型负责非事实性风格素材，Remotion 负责可控动画，FFmpeg 负责媒体检查。

## 2. 输入清单

### 必需

- 主题与一句话结论；
- 口播或需要表达的事实；
- 目标时长和平台；
- 场景语法与主要视觉主体；
- 事实、数据或产品结果来源。

### 可选

- 参考视频；
- 地图、截图、图表或真实录屏；
- 品牌配色和字体；
- 用户真人旁白或授权声线；
- 主体图片；
- 音乐和音效。

### 缺失处理

- 缺少事实来源：先核验，不直接制作事实性画面。
- 缺少准确结构：使用可信数据、真实截图、SVG 或人工描摹后再风格化。
- 缺少主体：生成或使用许可素材，并标记 `GENERATED`/`LICENSED`。
- 缺少旁白：先用文字时间估算做无声样片，正式成片前换为确认音频。

## 3. 生产阶段

### A. 立项

交付 `brief.md`：主题、观众、结论、事实边界、场景语法、画幅、时长、声音和交付范围。

### B. 声音与镜头同步设计

交付 `script.md` 与 `shotlist.md`。每句口播必须对应真实素材、剪纸主体、线条、标签或明确标注的解释动画。

### C. 素材准备

交付 `assets-manifest.md`。至少分离背景、证据、纸片层、线条/路径、标签图标、主体和字幕。记录来源、许可、原始文件、派生文件和真实性状态。

### D. 静态构图

先把所有图层静止摆好，检查主体层级、证据可读性、字幕安全区和画面焦点。静态构图未通过前不加入动画。

### E. 动画

按“镜头 → 证据/环境 → 纸片层 → 线条/方向 → 主体 → 字幕声音”的顺序实现。每完成一层就预览代表帧。

### F. 样片

先输出低分辨率或标准质量样片。样片允许 `PLACEHOLDER`，但必须在画面或交付说明中明确标记。

### G. 成片

替换全部占位素材，完成声音、字幕、视觉、转场和媒体参数检查。只有质量门槛全部通过后才能称为成片。

## 5. 角色分工

| 工具 | 职责 |
|---|---|
| Codex | 研究、分镜、素材清单、代码、渲染和验收编排 |
| Imagegen/绘图模型 | 纸张纹理、非事实性底板、主体插画和装饰 |
| GIS/SVG/图表工具 | 准确地图、几何、关系线、时间线和图表结构 |
| Python/Pillow | 抠图、透明通道、批量裁切与素材检查 |
| Remotion | 帧驱动动画、字幕、声音和可编辑模板 |
| FFmpeg/ffprobe | 媒体参数、抽帧、响度和异常帧检查 |

## 6. 交付标准

- 成片与样片路径明确；
- 工程可重新打开和渲染；
- 所有图层可独立修改；
- 字幕和旁白同步；
- 没有无意黑边、录屏 UI、绿边、黑帧或闪帧；
- 事实、时间、数据、路线、关系或产品结果经过核验；
- 素材来源、许可和生成状态完整；
- 媒体参数、响度和校验值已记录。

## 7. 复用方法

下一条视频只替换以下输入：

```text
场景语法与环境底板
真实证据和事实结构
纸片、线条、标签与图标
剪纸主体素材
口播与字幕
颜色 token
入场时间点
```

保持 `PaperLayerReveal`、`LineDraw`、`FlowMarks`、`CutoutSubject`、`EvidenceFrame`、`CaptionLayer` 和 `AudioTimeline` 组件不变，即可形成长期可复用的系列模板。
